# Instrucciones para agentes

Este repositorio corresponde a indexitba. Para publicar cambios, diagnosticar una version desactualizada o trabajar desde Codex Cloud, leer [DEPLOYMENT.md](DEPLOYMENT.md) antes de elegir el destino.

Una tarea de publicacion termina cuando el cambio esta comprobado en la URL solicitada. Si faltan acceso o destino, informar el bloqueo concreto y el estado alcanzado. Un push a GitLab no equivale a un despliegue.
